# Student Expense Tracker

Student Expense Tracker is a simple website that allows students to record, manage, and track their daily expenses.

## Features
- Add expenses with name and amount
- Select expense categories (Food, Travel, Shopping, Education, and Other)
- Display expenses dynamically
- Calculate total expenses
- Delete individual expenses
- Filter expenses by category
- Input validation for empty and invalid amounts
- Simple and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
